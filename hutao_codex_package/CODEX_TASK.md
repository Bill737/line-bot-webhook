# 胡桃人格整合任務

## 目標

將 LINE Bot 的回覆調整為更活潑、古靈精怪、俏皮且有互動感的胡桃風格，同時保留資訊正確、提醒清楚、圖片理解與嚴肅議題安全處理能力。

## 必須完成的修改

1. 閱讀 `hu_tao_persona_prompt.py` 與 `胡桃性格設計稿.md`，將可重用的 prompt 與情緒規則整合至現有 `main.py`。
2. 保留現有 `persona.py` 的安全邊界：不嘲笑喪親、疾病、自傷或恐慌，不捏造讀取手機，也不逐字複製遊戲台詞與歌曲歌詞。
3. 日常閒聊要有可感知的行為：俏皮開場、輕鬆吐槽、突然轉折、俏皮比喻或主動追問；每則只使用一至兩種玩笑手法，不能變成吵鬧或固定口頭禪。
4. 知識、操作、提醒與錯誤回覆必須先給清楚答案，再加入少量角色語氣；不可因角色扮演而省略時間、日期、步驟、錯誤原因或安全建議。
5. 依訊息情緒切換語氣：一般聊天活潑，焦慮或難過時先安定與關心，嚴肅議題立即收起玩笑並提供實際協助。
6. 整合 `free_music_generator.py`：預設在沒有 ElevenLabs 金鑰時使用 Hugging Face ACE-Step Space 生成原創中文人聲歌曲；Space 滿載、排隊逾時或 API 改版時，保留文字回覆並記錄簡短錯誤，不可讓 webhook 失敗。

## 整合規則

- 優先使用模組中的常數與函式，不要把同一份長 prompt 複製到多個地方。
- 不要覆蓋使用者目前的環境變數、資料庫、提醒流程、LINE 簽名驗證或圖片處理邏輯。
- 若現有系統已有 `HU_TAO_BEHAVIOR_GUIDANCE`，將新規則以清楚的附加段落合併，避免破壞既有正史與安全規則。
- 保持繁體中文輸出；避免使用會在 Windows 部署時造成亂碼的編碼方式。新增 Python 原始碼應使用 UTF-8。

## 驗證

在專案根目錄執行：

```bash
python -m unittest discover -s tests -v
python -m py_compile main.py persona.py hu_tao_codex_package/hu_tao_persona_prompt.py
```

至少要測試：一般閒聊、提醒建立與查詢、圖片訊息、歌曲搜尋、嚴肅議題、時間查詢，以及無法使用外部服務時的明確錯誤回覆。

## 完成條件

- 原有測試全部通過。
- 新增的人格測試全部通過。
- 沒有把 API key、LINE token、資料庫連線字串或個人資料寫進程式碼與 ZIP。
- 免費音樂後端的 `HF_TOKEN` 只能從 Render Environment 讀取；它是可選的，不得寫入 ZIP。ACE-Step 是共享服務，不能承諾每次立即成功。
- Git diff 可讀，沒有誤改 `data/` 內的執行資料。
